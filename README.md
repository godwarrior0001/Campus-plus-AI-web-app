# Campus-plus-AI-web-app
CampusPulse AI is a unified academic, hackathon, and campus deadline copilot built for Indian college students. Across India's 4.50 crore higher-education students (PIB AISHE 2023–24), critical exam forms, hackathon rounds, scholarship renewals, and placement notices get buried across WhatsApp groups, college ERPs, and emails.
